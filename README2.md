Project name: FitLog

Short description: This is a project where various type of exercise is shown and user can add them to their current day list or they can save it for later

Technologies used: HTML, CSS, JAVASCRIPT, TYPESCRIPT, NEXT.JS, TAILWIND, DAISYUI, REACT-TOAST

5 key features of the project: 
1.Responsive
2.Can add data
3.Display data
4.Remove data
5.Prevents from adding more than once
